# 杭州大富翁（hangzhou-tycoon-GPT）

基于 Cocos Creator 3.8 + TypeScript 开发的单机回合制地产经营策略游戏。

## 项目状态

- 当前阶段：阶段 0 — 工程初始化与基础架构
- 当前仓库状态：开发路线文档已建立；Cocos Creator 工程尚待本地编辑器初始化
- 产品需求基线：《杭州大富翁》游戏开发需求文档 V1.5

## 开发前必读

1. [开发路线与执行规范](docs/DEVELOPMENT_ROADMAP.md)
2. 按路线文档中的 T0-01 确认并记录 Cocos Creator 3.8.x 的具体补丁版本。
3. 按 T0-02 在本仓库根目录创建 Cocos Creator 2D 项目。
4. 工程初始化后，按阶段 0 的任务清单继续开发。

## 技术栈

- Cocos Creator 3.8.x
- TypeScript
- H5（Web）目标平台

## 重要约定

- 核心规则与 Cocos 表现层分离。
- UI 不直接计算或修改游戏经济数据。
- AI 与人类玩家共用规则结算接口。
- 不擅自修改已确认的产品规则；发现冲突先登记并确认。
- 每项开发任务必须有可验证的验收条件。

## 本地启动

当前仓库尚未包含 Cocos Creator 工程文件，因此暂时不能直接运行。完成 T0-01、T0-02 后，在 Cocos Creator 中打开仓库根目录并运行启动场景。具体步骤将随工程初始化结果补充。
